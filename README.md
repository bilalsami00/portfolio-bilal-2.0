# Bilal Sami — Software Engineer Portfolio

Personal portfolio website for **Muhammad Bilal Sami** (Bilal Sami).

Built with **Next.js** (Pages Router), **React**, **TypeScript**, and **Tailwind CSS**.

## Features

- Multi-page portfolio: Home, Projects, About, Contact, custom 404
- Light / dark theme toggle (classic teal light mode + dark-fantasy dark mode)
- Centralized content in `data/`
- Responsive layout and tasteful motion

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize content

Edit files under `data/`:

- `data/site.ts` — name, bio, SEO, contact placeholders
- `data/socials.ts` — social links
- `data/projects.ts` — project case studies
- `data/experience.ts` / `data/education.ts` — timeline placeholders
- `data/skills.ts` / `data/services.ts` — skills and capabilities

Replace any field marked as a **placeholder** with your real details. Do not invent employment, clients, or metrics.
